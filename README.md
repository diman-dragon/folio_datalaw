# Folio Desktop (folio_datalaw)

Просмотрщик PDF для настольных ОС на Tauri 2. **MVP: библиотека + открытие PDF.**
Отдельный проект; визуал (темы, иконки, цвета) взят из мобильного Folio.

## Стек
- Tauri 2 (Rust), плагин: `dialog`; команды `read_pdf`, `list_pdfs`, `files_exist`. Окно стартует развернутым (maximized).
- Фронтенд: чистый ES-JS без сборщика (`www/`), `pdfjs-dist` 6.4.299 копируется в `www/vendor/pdfjs` при `pnpm install`.
- Менеджер пакетов: pnpm. Тесты: `node --test` (юнит + сценарии на jsdom), `cargo test`.

## Старт (PowerShell)
```powershell
pnpm install        # зависимости + pdf.js и OCR-движок (~24 МБ, нужен интернет) в www/vendor
pnpm check          # контракт + тесты + clippy (после КАЖДОГО изменения)
pnpm dev            # окно приложения (tauri dev)
pnpm build          # установщик в src-tauri/target/release/bundle
```
Нужны Node 20+, Rust stable и системные зависимости Tauri (Windows: WebView2 и MSVC Build Tools; Linux: `libwebkit2gtk-4.1-dev` и др.).

## Что умеет MVP
- Библиотека: две секции, «Читаю сейчас» (начатые и не дочитанные) и «Остальные»; карточки с обложками и прогрессом. Показываются только файлы, которые существуют и читаются.
- Добавление: файлы (Ctrl+O, можно несколько) и целые папки (кнопка «Папка», Ctrl+Shift+O); перетаскивание файлов и папок в окно; клик по карточке открывает.
- Просмотр: два режима (лента / по одной странице, кнопка в шапке), масштаб (кнопки, Ctrl+колесо, Ctrl +/−/0, «По ширине» или «По странице»), переход по номеру страницы, PDF с паролем, Esc — в библиотеку.
- Выбранный инструмент виден на кнопке, а курсор мыши на странице становится этим инструментом (перо, маркер, ластик, выделение, подчёркивание).
- Миниатюры слева на прозрачном фоне, поверх страниц (страницы не сдвигаются): кнопка в шапке или левый край открывают, клик мимо закрывает, булавка закрепляет.
- Редактирование (кнопка с карандашом): перо, маркер, ластик, выделение текста цветом, подчёркивание, 12 цветов, отмена / возврат (Ctrl+Z / Ctrl+Y). Текст выделяется мышью, Ctrl+C копирует, двойной клик выбирает слово.
- Пометки сохраняются для каждого документа и возвращаются при открытии. Отмена / возврат: кнопки в шапке всегда на виду.
- OCR для сканов (значок в палитре): страница или весь документ, 5 языков; распознанный текст выделяется и копируется, результат запоминается.
- В режиме «по страницам» листают стрелки ← →, PgUp/PgDn, Home/End и колесо мыши.
- Запоминает страницу и масштаб каждого документа, тему (светлая / тёмная).
- Убрать из библиотеки: корзина на карточке или правый клик. Файл на диске не удаляется.

## Структура
```
www/                  фронтенд (frontendDist)
  index.html, css/    разметка и стили (theme.css — токены цветов)
  js/core/            bus, storage, theme, format, strings
  js/data/            library (записи), covers (обложки)
  js/io/              bridge (единственное место с __TAURI__), read-pdf, pick-pdfs, drop-files
  js/formats/pdf/     pdfjs, open-doc, close-doc, page-list/layout/painter, render-queue, render-page, thumb-list, zoom, page-at, cover
  js/ui/              экраны и панели; annot-*, viewer-draw, tools-panel, text-* — редактирование
  js/app/             сценарии: открыть, импортировать, удалить
src-tauri/            Rust: lib.rs, commands/*.rs, pdf_guard.rs, pdf_scan.rs (+ тесты)
scripts/              проверки контракта, bump версии, copy-vendor
test-fixtures/        PDF для тестов (обычный и с паролем «secret»)
www/js/scenarios/     сценарные тесты на jsdom (библиотека, просмотр, редактирование, OCR-панель)
```

## Известные ограничения MVP
- Нет поиска по тексту. Выделять можно только страницы с текстовым слоем (у сканов сначала нужен OCR; без интернета при установке движок не скачается, остальное работает).
- Размеры страниц до первой отрисовки берутся по первой странице: в документах с разными форматами возможен небольшой сдвиг при прокрутке.
- Файл целиком читается в память (лимит 512 МБ). Для очень больших PDF позже нужна подгрузка по частям.
- Библиотека хранит путь к файлу. Файл переместили — карточка остается, при открытии сообщение «Файл не найден».
- Обложка создается при первом открытии файла.
- Нет открытия двойным кликом из проводника (ассоциация `.pdf`) и CLI-аргумента.
- История отмены живёт, пока документ открыт: после закрытия пометки сохраняются, а шаги отмены нет.
- Установщик получается крупным: OCR-движок вшивается в приложение.
- Пометки хранятся рядом с библиотекой в данных приложения (localStorage), а не внутри PDF: в другой программе они видны не будут. Запись в сам PDF — отдельная задача.
- Данные библиотеки и пометок лежат в localStorage веб-вью (папка данных приложения), объём ограничен несколькими мегабайтами.
