# Реестры folio_datalaw

Порядок работы: **конвенция (`CONVENTIONS.md`) → реестры (этот каталог) → код.** Не начинайте с поиска по коду: ответ на «где это» и «что это затронет» уже здесь.

Реестры — источник правды о составе проекта. `pnpm check` сверяет их с кодом (проверки `scripts/checks/reg-*.mjs`): расхождение = красный контракт, сообщение говорит, что дописать или удалить.

| Файл | Что в нём | Чем сверяется |
|---|---|---|
| `components.json` | все компоненты: вид, назначение, файлы, id разметки, иконки, публичные классы, зависимости (`uses`) | `reg-components`, `reg-deps`, `reg-ids`, `reg-icons`, `reg-classes` |
| `kinds.json` | виды компонентов и что каждому можно использовать | `reg-components`, `reg-deps` |
| `events.json` | события: шина, DOM, Tauri; кто шлёт и кто слушает | `reg-events` |
| `storage.json` | ключи localStorage и IndexedDB: владелец, формат, файлы, чем чистится при удалении документа | `reg-storage` |
| `commands.json` | команды Rust, их защита, JS-обёртки, права Tauri | `reg-commands` |
| `shortcuts.json` | горячие клавиши и жесты по областям | `reg-shortcuts` |
| `tokens.json` | цветовые токены обеих тем и переменные CSS, задаваемые из JS | `reg-tokens` |
| `debt.md` | известные нарушения конвенции и ошибки, ещё не исправленные (вручную) | ревью |

Реестры в других местах: тексты интерфейса — `www/js/core/strings.js` (`reg-strings`), иконки — `www/img/icons.svg`, исключения из тестов — `scripts/checks/tests-exempt.json`.

## Как пользоваться
- **Нашёл задачу** → `components.json`: какому компоненту она принадлежит, что он использует (`uses`) и кто использует его (ищите его ключ в чужих `uses`: это то, что может сломаться).
- **Добавляю файл** → найти владельца; нет подходящего — сначала карточка нового компонента.
- **Добавляю импорт чужого компонента** → проверить по `kinds.json`, что можно; дописать в `uses`; цикл запрещён.
- **Меняю событие, ключ хранилища, команду, клавишу, токен** → сначала соответствующий реестр, потом код.
- Закрыл пункт из `debt.md` → удалить запись в том же шаге.

## Формат карточки компонента
```json
"zoom": {
  "kind": "ui",
  "about": "одна фраза о назначении",
  "files": ["www/js/ui/viewer-zoom.js", "www/js/formats/pdf/*"],
  "ids": ["zoom-in"],
  "icons": ["zoom-in"],
  "classes": ["btn"],
  "uses": ["bus"]
}
```
`files` — пути от корня; `*` заменяет часть имени внутри одной папки. Тесты в `files` не пишутся: они принадлежат владельцу своего файла. `classes` нужен только публичным примитивам (`ui-kit`).
