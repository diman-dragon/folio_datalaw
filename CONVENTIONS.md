# Конвенция folio_datalaw

## 1. Атомарность
- 1 файл = 1 ответственность. Первая строка каждого файла (`//` в JS и Rust, `/* */` в CSS) — одна фраза об этой ответственности.
- Лимиты размера: JS 110 строк, CSS 70, `.mjs` 70, Rust 120. Превысили — делим по ответственности.
- Один Tauri-command = один файл в `src-tauri/src/commands/`.
- Реэкспорты и «общие» файлы без логики не создаем.

## 2. Проверка при КАЖДОМ изменении
```
pnpm check
```
Это по порядку: контракт (`scripts/checks/*`) → `node --test` → `cargo clippy -D warnings` → `cargo test`.
- Нет зеленого `pnpm check` — изменение не принято.
- Одно изменение = один файл = одна проверка. Пачки файлов без проверки между ними запрещены.
- Новый файл логики идет с тестом `*.test.js` рядом (Rust — `*_tests.rs`).
- Ошибку проверки чиним в том же шаге.

Что проверяет контракт: размер файлов, заголовок-ответственность, резолв импортов, изоляция Tauri (`__TAURI__` только в `io/bridge.js`), существование id из JS в `index.html`, существование иконок в `icons.svg`, единая версия в `package.json` / `tauri.conf.json` / `Cargo.toml`.

## 3. Версия
Каждое изменение поднимает последнюю цифру: `pnpm bump`, затем запись сверху `CHANGELOG.md`. `0.1.0` — только по команде владельца.

## 4. Безопасность
- Файловая система доступна только из Rust. Единственная точка чтения — `read_pdf` через `pdf_guard` (расширение `.pdf`, сигнатура `%PDF-`, лимит размера).
- Права в `capabilities/default.json` — минимум. Расширяем только вместе с задачей, которой это нужно.
- PDF — недоверенный ввод: `isEvalSupported: false`, строгая CSP, скриптов PDF нет.

## 5. Форматы и переносимость
- Весь код вьювера и библиотеки — чистый JS без Tauri. Tauri знает только `www/js/io/bridge.js`.
- Новый формат — отдельная папка `www/js/formats/<fmt>/`.
