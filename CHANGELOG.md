# Changelog
## 0.0.4
- Библиотека: добавлять можно файлы и целые папки (кнопка «Папка», Ctrl+Shift+O, либо перетаскиванием папки в окно). Папка обходится рекурсивно (глубина до 8, до 5000 файлов), уже добавленные файлы пропускаются, виден прогресс «Добавляю 12 / 300».
- Библиотека разделена на две обособленные секции без повторов: «Читаю сейчас» (начатые и не дочитанные, отдельной панелью сверху) и «Остальные».
- Показываются только читаемые документы: файлы, которых нет на диске, скрываются (проверка делается в Rust при каждом обновлении и при возврате в окно). Внизу счётчик скрытых и кнопка «Убрать из библиотеки». Запароленные и повреждённые файлы при пакетном добавлении в библиотеку не попадают.
- Новая иконка приложения: свиток, освещённый фонариком (окно, установщик, логотип в шапке и на пустой библиотеке). Исходник генератора: `src-tauri/icons/source/make_icon.py`.
- Подчёркивание текста сдвинуто чуть ниже строки.
- Булавка палитры инструментов перенесена в левый верхний угол. В сетке на её месте кнопка OCR.
- Отмена / возврат: кнопки в шапке видны всегда (не только при открытой палитре), в подсказке число доступных шагов, история ограничена 1000 шагами. Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z.
- OCR (перенесён из Android-версии): кнопка в палитре открывает панель распознавания: страница или весь документ, языки русский / English / Italiano / Српски / Srpski, прогресс и отмена. Результат делает скан выделяемым и копируемым, хранится в IndexedDB и возвращается при следующем открытии. Движок и языки (около 24 МБ) скачивает `pnpm install` (или `pnpm run fetch-ocr`).
- ESLint в `pnpm check` (неопределённые имена и лишние импорты): ловит класс ошибок, который контракт не видел.
- Rust: команды `list_pdfs` и `files_exist` (`pdf_scan.rs`, 7 тестов).

## 0.0.3
- Миниатюры больше не сдвигают страницы: панель всегда накладывается поверх. Открывается кнопкой в шапке или наведением на левый край, закрывается кликом в любом другом месте (и по Esc). Булавка закрепляет панель: она остаётся открытой при кликах мимо и запоминается между запусками.
- Редактирование (перенесено из Android-версии, без стилуса): кнопка «карандаш» в шапке открывает перетаскиваемую палитру.
  - Инструменты: перо, маркер, ластик (стирает штрих целиком), выделение текста цветом, подчёркивание текста; 12 цветов и свой цвет.
  - Выделение текста мышью: протяжка выделяет, двойной клик выделяет слово, ручки по краям меняют границы, всплывающее меню: копировать / выделить / подчеркнуть. Ctrl+C копирует.
  - Отмена и возврат одним общим стеком для всех страниц: кнопки в шапке, Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z.
  - Esc по порядку закрывает: выделение, инструмент, панель миниатюр, затем просмотр.
- Новое по сравнению с Android: пометки сохраняются для каждого документа и возвращаются при следующем открытии (хранятся в данных приложения, в сам PDF не записываются). При удалении из библиотеки пометки удаляются.
- Ластик теперь проверяет отрезки штриха, а не только его точки: быстрый штрих мышью, состоящий из нескольких точек, стирается, если его пересечь.
- Не перенесено намеренно: стилус (нажим, защита от ладони, режим «только стилус») и распознавание текста OCR.

## 0.0.2
- Окно открывается развернутым на весь экран рабочей области (maximized), но не в полноэкранном режиме. Плагин window-state убран: он восстанавливал бы старый размер.
- Два режима просмотра: лента и по одной странице (кнопка в шапке, выбор запоминается). В режиме «по страницам»: стрелки, PgUp/PgDn, Home/End и колесо листают; «По странице» подгоняет страницу целиком.
- Между страницами заметный промежуток (28 px), тень покрепче, на еще не отрисованной странице виден ее номер.
- Слева панель миниатюр на прозрачном фоне: закрепляется (кнопка-булавка или кнопка в шапке), в откреплённом виде выезжает при наведении на левый край. Текущая страница подсвечивается, клик переходит.
- Скорость отрисовки (переписано):
  - аппаратное ускорение canvas в pdf.js (`enableHWA`, по умолчанию выключено);
  - сначала мгновенное превью низкого разрешения, потом чёткий рендер;
  - единая очередь с приоритетом по близости к центру экрана, 2 задачи параллельно, страницы, ушедшие из окна до рендера, отменяются;
  - при зуме старые холсты остаются (растягиваются), страницы перерисовываются один раз после паузы, без белой вспышки;
  - рендер идёт только рядом с окном просмотра, дальние страницы освобождаются после остановки прокрутки;
  - обложка берётся из уже нарисованной первой страницы (без второго рендера);
  - миниатюры рисуются с самым низким приоритетом.

- Rust: команда `read_pdf` с охранником `pdf_guard` (расширение, сигнатура, лимит 512 МБ).
